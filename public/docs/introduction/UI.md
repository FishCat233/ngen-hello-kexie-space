# UI 设计

## 一、什么是 UI 设计

> 《百度百科》对 UI 设计的定义是：“UI 即 User Interface（用户界面）的简称，UI 设计是指对软件的人机交互、操作逻辑、界面美观的整体设计。”

用户界面（User Interface）是一个广义的概念，指人与机器在互动过程中所接触的界面。以手机为例，屏幕上的一切可视、可操作部分都属于用户界面——我们通过界面向设备发出指令，设备再给出相应的反馈。负责设计这套界面视觉与逻辑的人，就是 UI 设计师。

通常所说的 UI 设计，多指 **UI 视觉设计**，主要负责 App、Web、H5 等页面的色彩、布局、图标、字体等方面的设计工作。但随着互联网的发展，纯视觉的岗位需求正在减少，行业对 UI 设计师提出了更高要求：需要懂交互设计、理解产品逻辑，也就是具备用户体验设计（User Experience，国内称 UE，国外称 UX）的思维。如今许多团队更强调“全链路设计”——从用户研究、交互原型到视觉落地，设计师需要参与更多环节。

## 二、基础素养

要真正入门并胜任 UI 设计，核心需要打牢以下四块基础：

### 1. 色彩

需要理解色彩的基本原理与配色方法。色彩最难把控的地方在于容易被过度使用。如果你是初学者，建议先以柔和、统一的色调打底，只在需要强调信息或引导操作时，才使用更醒目的色彩。

### 2. 字体与排版

文字往往占据整个设计内容 80% 以上的面积，因此掌握正确的字体选择与排版方式至关重要。无论设计风格如何变化，都应把“清晰易读”作为字体与排版的首要目标。

![古典字体样张（Type Specimen），字体设计的经典呈现](/docs/introduction/image/ui/960px-A_Specimen_by_William_Caslon.jpg)

### 3. 动效

合理的动效能显著增强产品的用户体验，让界面更有生命力、更吸引人。前提是动效必须**快速、流畅，并且符合用户的操作预期**——炫技式的动效反而会拖累体验。

![基于手势的用户界面动效示意](/docs/introduction/image/ui/Gesture-based_User-Interface.gif)

### 4. 图标

优秀的图标往往与现实中的事物紧密关联，例如相机、垃圾桶、云朵等，能让用户一眼识别出它所代表的功能。因此应尽量使用辨识度高、含义明确的图标，避免让用户产生歧义。

## 三、就业与发展方向

UI 是研究人机交互的学科，目前主要应用于软件、互联网、移动智能设备、游戏以及虚拟现实等领域。这些新兴且活跃的方向整体需求量较大，国内众多头部企业（百度、腾讯、中国移动、联想、网易、微软、淘宝等）都已设立专门的 UI 设计部门。

学完 UI 设计后，就业面很广，除了传统的视觉设计，还可以向以下方向深耕：

### PC 端（WUI）

从事 PC 端设计的常被称为 WUI（Web User Interface）设计师或网页设计师，负责电脑上的操作界面，例如电脑版 QQ、微信、Photoshop 等软件，以及各类网页的按钮、图标与布局。

### 移动端（GUI）

移动端设计常被称为 GUI（Graphics User Interface）设计师，因为移动产品中大量使用图形界面。手机上的所有界面——聊天窗口、桌面、图标以及点击后的反馈——都属于移动端 UI 设计的范畴。

### 游戏 UI 与其他方向

此外还有游戏 UI，以及 VR 界面、AR 界面、ATM 界面、智能电视、车载系统等嵌入式设备的界面。这些方向当前用户规模相对较小，但属于“需要且有潜力”的领域，未来可能迎来爆发。

## 四、常用工具

UI 设计并非遥不可及的技能，掌握合适的工具能大幅提升效率。当前主流工具包括：

- **Figma**：基于浏览器的协作式设计工具，目前行业使用最广泛，支持多人实时协作与交付。
- **即时设计 / MasterGo**：国产在线设计工具，功能对标 Figma，适合国内团队协作。
- **Sketch**：macOS 平台老牌界面设计工具。
- **Adobe XD**：Adobe 推出的轻量级原型与界面设计工具。
- **Photoshop / Illustrator**：处理位图与矢量图形的经典软件，常用于素材制作与精修。
- **蓝湖 / Pixso**：设计稿交付与标注工具，便于设计与开发协作。

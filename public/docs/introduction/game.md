# 游戏开发方向介绍

> 三院科协 · 游戏开发方向
> 引擎：Unity · 语言：C#

## 总体介绍

游戏开发方向主攻 **Unity 程序**，使用 **C#** 语言开发游戏的核心玩法、用户界面（UI）、交互逻辑、动画和特效等。

### 技能树

- **编程语言** — C# 是 Unity 开发的核心语言，必须精通。熟悉 Lua 等脚本语言会是加分项。
- **Unity 引擎** — 精通 Unity 的架构和核心模块，包括场景管理、物理系统、动画系统、UI 系统等。
- **程序基础** — 拥有扎实的计算机科学基础，熟练掌握数据结构、算法和设计模式。

### 四大发展方向

- **客户端** — 负责 Gameplay、UI 搭建、系统设计、3C 优化等基础逻辑与架构的实现。离玩家最近，也是最核心的岗位。
- **TA（技术美术）** — 专注于 Shader 编写、渲染管线优化，追求极致的画面表现和性能，是技术与艺术的桥梁。
- **工具链** — 开发编辑器插件、自动化流程、AI 通用管线，提升整个团队的生产效率。
- **底层/引擎** — 深入引擎底层，进行核心模块优化和新技术预研，是团队的技术攻坚力量。

### 学习内容

游戏开发需要学习的内容是其他方向的数倍之多。需要同时掌握多项技能、多方技术栈，以及堆成山的 API 与组件。**这是不可避免的，也是命中注定。**

## 主流引擎与选择心态

- **Unity** — C# / .NET 生态。主要脚本语言为 C#，可接入 .NET 生态。我们的主攻方向。
- **Godot** — GDScript / C# / C++。最常用 GDScript（类似 Python），官方也提供 C# 支持。GDExtension 可通过 C++ 写扩展。
- **Unreal Engine** — C++（UEC++）。UE C++ 为主，是 C++ 的魔改版本，与标准 C++ 最大的不同之一是有 GC。
- **Cocos Creator** — TypeScript / JavaScript。轻量高效，特别适合 2D 游戏与微信小游戏开发。

### 辅助技术栈

- **Lua** — 游戏热更新的事实标准，几乎每个商业手游都会集成 Lua 虚拟机作动态更新。
- **Python** — DCC 工具（Maya / Blender / Houdini）的脚本接口大多是 Python，也适合写批量处理管线。
- **JavaScript / TypeScript** — WebGL / Canvas 是独立游戏的热门平台，TypeScript 也让 Web 游戏开发更具工程性。

### 选择心态

> 引擎只是工具，不是根基。无论选择哪款引擎，它都只是帮助你把脑中的知识与经验具象化的桥梁。不必拘泥于"Unity 国区作死""UE 难度陡峭""Godot 无岗位"这些外部声音。**不要怕选错引擎，也不要怕转引擎困难。** 只要根基足够牢固，引擎的差异不过是语法与习惯的不同。
>
> **真正重要的是：你能否把自己的知识体系和创意落地。**

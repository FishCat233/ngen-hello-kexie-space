# 嵌入式开发学习方向

> 从零起步，一步步把创意变成通电运行的实物

​	嵌入式开发是硬件部的核心学习方向。我们不追求一上来就啃复杂芯片，而是带你沿着一条清晰的成长路径循序渐进：从单片机基础到 STM32 外设驱动，从传感器应用到项目实战，直至拓展 RTOS 与物联网。无论你是零基础新手，还是已有项目经验的爱好者，都能在这里找到适合自己的起点。

## 一、嵌入式开发学习路径

### 入门阶段 | 51 单片机基础 · 打好地基

​	从 **51 单片机**入手，掌握 GPIO、定时器、中断等核心概念，配合 C 语言与寄存器操作，理解"代码如何驱动硬件"这一嵌入式的底层逻辑。

### 进阶阶段 | STM32 开发 · 走向工程化

​	进入 **STM32** 平台，学习 HAL 库与标准库、各类外设驱动，掌握 **I2C / SPI / UART** 等常用通信协议，具备独立编写外设程序的能力。

### 应用阶段 | 项目实战 · 综合能力落地

​	在真实项目中融会贯通：**传感器数据采集与融合**、实时性处理，完成如智能小车、数据采集系统等完整作品，打通"设计—制作—调试—成品"全流程。

### 拓展阶段 | RTOS · 物联网 · 机器人

​	向更高维度延伸：**RTOS** 实时操作系统、**ESP32** 物联网开发，并可进一步接触 **ROS2** 等机器人中间件，为电子设计竞赛与自主科创项目储备硬核实力。

## 二、配套开发平台与传感器

​	围绕上述路径，我们提供 51 单片机、STM32 等主流开发平台，配套温湿度、红外、蓝牙、陀螺仪等各类常用传感器，覆盖从入门单片机到嵌入式项目开发的全部需求。仓库同时储备海量贴片、直插电阻、电容、芯片等常用元器件，无需自行采购耗材，大家可以放心动手反复试验。

## 三、工艺制作与电路调试支撑

- **焊接工艺**：电烙铁、焊台、热风枪、加热台等全套焊接工具，支持直插、贴片元器件的焊接练习。
- **测试调试**：直流稳压电源、数字示波器、信号发生器、高精度万用表等专业仪器一应俱全，满足 PCB 制版后的信号测量与故障排查。
- **PCB 制版**：除常规 PCB 设计打样外，学长学姐还会手把手带你在覆铜板上手搓电路板，体验从图纸转印、腐蚀到钻孔成型的完整制版流程，吃透 PCB 底层工艺。

## 四、网盘资源与实践空间

​	部门搭建了专属科协网盘资源库，沉淀了电子专业课件、课堂笔记、历年期末试卷与参考答案，以及考研网课、复习讲义、真题资料，各类简历模板、项目报告范文、竞赛文档模板也一应俱全，兼顾课内学业、考研备考与竞赛求职。

​	同时，硬件部为每位成员分配独立宽敞的固定工位，实验室全天开放空调、稳定电源与高速免费 WiFi，让你在充足的自主空间里安心打磨项目、调试电路，把想法一步步变成可以通电运行的实物作品。
